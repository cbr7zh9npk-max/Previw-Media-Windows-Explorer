# Previw-Media-Windows-Explorer
Simple app to preview videos and photos in File Explorer for Windows 11

Simply hold shift while selecting a video or image file in Windows file explorer and it will preview the file with the option to fast forward or back and preview the next or previous file in the same folder. 
To install it, simply exctract the zip file to wherever on your computer and run build.bat to launch the program. 

The detailed instructions on hotkeys are in the readme.txt file. 

The make the app start on boot, simply create a shortcut of "build.bat" file and use Windows + R to run: shell:startup. Place the shotcut of build.bat in startup folder that will open after running shell:startup. The program will then launch on boot.
